About SpeedSpot

A community map of India's internet

SpeedSpot Mapper turns everyday speed tests into a shared picture of how well each neighbourhood is connected, so people can choose wisely and cities can plan better.

{{ icon("gauge") }} Add your test {{ icon("steps") }} How it works

Who it's for

{{ icon("home") }} Residents and renters Check a neighbourhood before you move, and compare providers before you sign up.
{{ icon("users") }} Students and remote workers Find reliable spots for classes, calls and uploads.
{{ icon("route") }} Travellers See which provider works where you're going.
{{ icon("insights") }} City planners Spot under-served areas using area-level reports, never personal data.

What we stand for

  • {{ icon("check", "sm") }}Honest numbers. An area only gets a score with enough tests, and we never invent results.
  • {{ icon("check", "sm") }}Privacy first. No exact locations, no stored IP addresses, no accounts.
  • {{ icon("check", "sm") }}Open and simple. Plain language for everyone, from students to grandparents.
